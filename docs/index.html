What is this?

A free, unofficial Stremio add-on listing the highest-rated films of every year from 1920 to now, using IMDb's public data.

How it works

Select a year in Stremio. Films are ordered using a vote-weighted score, with a minimum number of votes for credible rankings.

Filtering

Only feature-length films rated 6.0 or higher. Documentaries are included; shorts and concert films aren't. Indian-language films from 2015 onwards are excluded under the existing ranking rule.

Open source

Entirely hosted on GitHub, rebuilt weekly and published to GitHub Pages. View the source ↗

This is a catalogue-only add-on: it supplies film lists, not streams. Keep your existing Stremio streaming add-ons to watch films.
